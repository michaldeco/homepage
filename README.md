# michaldeco.com

Personal homepage / freelancer profile. Plain HTML + CSS, no build step.

- `index.html` — content (replace the `[placeholders]`)
- `style.css` — styles (light/dark follows the system setting)

## Local preview

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

Hosted on Cloudflare (Pages / Workers static assets), connected to this repo.
Build command: none. Output directory: `/`.
